# MVP-R01-002 每周健康回顾

## 1. 文档信息

- 分类：`R01 恢复与周期回顾`
- 优先级：P1
- 首发端：iPhone
- 状态：已完成首期
- 数据位置：本机已有 `ReportDaySummary` 的确定性派生

## 2. 用户问题

用户需要快速知道一周的数据是否足够、与前一周相比是否有稳定变化，以及下一周只做哪一件低负担的事。

## 3. MVP 范围

1. 展示数据天数和睡眠、压力、HRV、活动四项覆盖。
2. 展示有效评分日平均值。
3. 两周各至少 3 个评分日时才输出周环比。
4. `-3...3` 分视为基本持平。
5. 只使用明确的 positive/caution 贡献项生成支撑项和关注项。
6. 当前周按已经过的自然日计算覆盖；历史周按完整 7 天计算。
7. 输出一个确定性的下一周行动，不使用生成式 AI。

## 4. 数据与隐私

- 不保存新记录，不新增 CloudKit schema。
- 不读取或展示 HealthKit 原始样本。
- 缺失指标不按零值参与计算。
- 历史周不复用无关的 30 天健康画像结论。

## 5. 验收标准

1. 无数据时不产生评分或方向结论。
2. 前两天即使覆盖完整也保持“样本积累中”。
3. 周范围切换后标题、覆盖和结论均对应所选周。
4. 相同输入产生相同输出。
5. 聚焦测试覆盖样本阈值、持平区间、缺失数据和贡献项筛选。

## 6. 后续范围

- 行动完成事实汇总。
- 静息心率方向。
- 隐私裁剪后的分享导出。
- 跨时区、夏令时与跨年专项测试。

# MVP-P01-002 健康重点判断与睡眠承接

## 1. 文档信息

- 分类：`P01 健康档案与长期画像`
- 优先级：P1
- 首发端：iPhone
- 状态：已完成第二阶段
- 数据位置：复用现有 `HealthProfileSummary`、`SleepData` 与 `SleepSessionSummary`，不新增持久化或云字段

## 2. 用户问题

健康页“现在最值得关注”当前按“行动建议、风险、变化”的固定分组顺序取前三项。普通建议可能先于更需要留意的风险，同一健康模块也只保留最先出现的一项，没有比较证据强度与数据完整度。

从关注项进入睡眠页后，首屏先重复展示时长、评分和阶段指标，真正解释“为什么值得关注、今晚做什么”的睡眠洞察与恢复行动位于较后位置，入口与详情缺少同一条判断链。

## 3. MVP 范围

### 3.1 健康重点判断

1. 将行动建议、风险倾向和近期变化放入同一候选池评分，不再按数据类型固定分组先后。
2. 排序优先级依次考虑：高优先级行动、风险变化或风险倾向、中优先级行动、观察变化、低优先级保持项与正向变化。
3. 同一健康模块只展示一项，但必须保留该模块评分最高的候选项。
4. 对样本不足或未授权模块降低排序权重，避免低依据判断压过有充分样本的重点。
5. 最多展示三个不同模块；第一项作为主关注，另外两项作为次级关注。
6. 每项明确区分“判断依据”和“下一步”，不再用一段文案同时承担原因与行动。
7. 当没有值得升级的风险或行动时，展示稳定保持项；档案建立中继续展示数据覆盖说明。

### 3.2 睡眠页承接

1. 首屏展示昨夜睡眠状态、核心指标和一条确定性的“昨夜重点”。
2. “昨夜重点”优先复用本机 `SleepSessionSummary.insight`；缺少完整洞察时，根据时长缺口、评分与深睡占比生成保守提示。
3. 同屏区分“依据”和“今晚行动”，让用户从健康重点进入后立即知道为什么和做什么。
4. 调整页面顺序为：昨夜概览 → 昨夜重点 → 恢复计划 → 睡眠时段与明细 → 结构分析 → 环境管理。
5. 删除首屏重复的大号时长/评分展示，保留有增量信息的阶段、心率和呼吸明细。
6. 图表标题使用具体含义，避免只写“分析”；所有无数据状态保持保守表达。
7. 睡眠页用户可见文字不添加动画。

### 3.3 第二阶段：内容可信度与连续趋势

1. 每个健康重点补充“观察窗口 + 样本状态”，让用户知道内容来自哪个时间范围、依据是否充分。
2. 标题随内容强度变化：存在风险或高优先级行动时使用“现在最值得关注”；只有观察项时使用“接下来值得观察”；只有稳定项时使用“目前值得继续保持”。
3. 档案建立中不沿用风险语气，明确提示当前还在补齐本地样本。
4. 睡眠重点增加“连续趋势”，有至少 3 晚数据时给出近 7 晚平均时长和未达目标晚数；不足 3 晚时明确说明仍以单晚观察为主。
5. 单晚深睡占比较低只输出观察提示；近 3 晚至少 2 晚都偏低时，才升级为连续趋势提示。
6. 昨夜状态尚可但近期多晚时长不足时，不输出“基础较稳”的结论，改为“昨夜尚可、近期仍需观察”。
7. 复用睡眠洞察前校验会话日期；日期明显不匹配时不得因为时长接近而复用旧结论。

## 4. 排序合同

候选项使用确定性权重，分数仅用于页面内部排序，不作为用户健康分数展示：

| 候选类型 | 基础权重 |
|---|---:|
| 高优先级行动 | 120 |
| 风险变化 | 115 |
| 风险倾向 | 110 |
| 中优先级行动 | 90 |
| 观察变化 | 72 |
| 低优先级保持项 | 55 |
| 稳定变化 | 45 |
| 正向变化 | 40 |

数据完整度修正：已同步不扣分，派生数据扣 5 分，样本不足扣 24 分，未授权扣 36 分；不适用或未启用模块不产生惩罚。相同权重时按候选类型、模块和标题稳定排序。

## 5. 数据与隐私边界

- 只消费现有本机聚合结果，不新增 HealthKit 查询。
- 不新增 SwiftData 模型、App Group 字段或 CloudKit record type。
- 不上传睡眠阶段、心率明细、主观记录或自然语言洞察。
- “风险”仅表示生活方式观察优先级，不描述疾病概率、诊断或治疗建议。
- 数据不足时必须降低结论强度，不能把缺失值当作异常值。

## 6. 不做

- 不修改健康档案成长指数和各维度评分算法。
- 不修改睡眠评分、阶段推断和熬夜识别算法。
- 不新增医疗告警、疾病筛查、用药建议或自动诊断。
- 不修改 HealthKit、CloudKit 或应用签名权限。

## 7. 验收标准

1. 高优先级行动优先于普通风险，风险优先于中低优先级保持建议。
2. 同模块有多条候选时，留下权重最高的一条。
3. 未授权或样本不足的判断会被降级，但仍可在没有更可靠候选时显示。
4. 主关注卡可读出模块、优先级、判断依据和下一步，并能进入正确详情页。
5. 睡眠页有数据、无数据和洞察尚未生成三种状态都能给出保守且可执行的首屏内容。
6. 睡眠页不重复展示同一组大号时长和评分。
7. iPhone 紧凑与扩展布局均无水平溢出，VoiceOver 能按判断链读取内容。
8. 页面用户可见文字不添加动效。
9. 健康重点卡可以读出观察窗口与样本状态，标题语气和当前最高内容强度一致。
10. 睡眠页在有连续样本时展示近 7 晚趋势，旧会话洞察不会覆盖昨夜判断。
